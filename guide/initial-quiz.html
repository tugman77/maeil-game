초성과 뜻을 함께 보세요

초성은 한글 음절의 첫소리입니다. 예를 들어 김밥의 초성은 ㄱㅂ입니다. 하지만 초성만으로는 답이 여러 개일 수 있으므로, 화면에 보이는 분야와 뜻 설명을 함께 읽어 주세요.

먹거리·주방·생활용품·교통·시설·동물·자연 등에서 직접 작성한 90개 문제를 준비했습니다. 유행어나 특정 세대만 아는 표현보다 일상에서 접하는 단어를 중심으로 골랐습니다. 같은 단어가 이후 판에 다시 나올 수 있습니다.

휴대폰에서 글자 버튼으로 답 만들기

  1. 문제의 초성과 뜻 설명을 읽습니다.
  2. 아래의 글자 버튼을 답의 순서대로 누릅니다.
  3. 답이 완성되면 정답 확인을 누릅니다.
  4. 확인한 뒤 다음 문제를 누르고, 다섯 번째 문제 뒤에는 결과 보기를 누릅니다.

사용한 글자는 답 칸에 나타나고 아래 버튼은 흐려집니다. 같은 글자가 두 번 필요한 단어에는 그 글자 버튼이 두 개 있습니다. 답 칸의 글자를 누르면 그 글자만 지우고, 지우기는 마지막 글자를 지웁니다. 되돌리기는 최근 입력 편집을 되돌립니다. 확인한 정답·오답 기록이나 사용한 힌트는 되돌리지 않습니다.

힌트와 정답 보기

힌트는 문제마다 두 번 쓸 수 있습니다. 첫 번째는 추가 설명, 두 번째는 정답의 첫 글자입니다. 힌트가 답을 자동으로 입력하지는 않습니다. 힌트를 사용한 뒤 맞혀도 직접 맞힘에 포함되고, 사용 횟수는 결과에 따로 표시됩니다.

막히면 정답 보기를 누르세요. 안내를 읽고 5초 안에 한 번 더 누르면 정답을 보여 줍니다. 정답을 본 문제는 직접 맞힘에 포함되지 않으며 다음 문제로 계속할 수 있습니다. 편집을 하거나 기다리면 확인 상태가 취소됩니다.

뜻과 초성에 모두 맞는 복수 정답을 등록한 문제도 있습니다. 예를 들어 날개를 돌려 바람을 보내는 기계를 묻는 ㅅㅍㄱ 문제는 선풍기와 송풍기를 모두 인정합니다. 인정하는 정답은 문제 확인 뒤 함께 보여 줍니다.

키보드를 쓰고 싶다면

키보드로 직접 입력하기를 펼쳐 답을 쓸 수도 있습니다. 띄어쓰기는 무시하고 완성된 한글을 비교합니다. 한글을 조합하는 도중의 Enter는 제출하지 않습니다. 조합을 마친 뒤 Enter를 누르거나 정답 확인을 누르세요. Tab으로 버튼을 고르고 Enter나 공백으로 누르는 조작도 가능합니다.

오늘의 도전과 이어하기

한국 날짜 기준으로 같은 날에는 누구나 같은 보통 난이도 다섯 문제를 같은 순서와 같은 글자 배치로 풉니다. 정답 보기를 이용했더라도 다섯 문제를 끝까지 진행해 결과를 보면 오늘의 도전 출석으로 기록합니다. 직접 맞힌 문제 수와 정답 보기 사용 여부는 구분해 보여 줍니다.

입력한 글자와 힌트·오답·진행 상태는 이 기기의 브라우저에 저장합니다. 다른 앱이나 탭으로 가면 자동 일시정지하고, 다시 열면 이어하기로 계속할 수 있습니다. 저장소를 사용할 수 없는 환경에서는 해당 창 안에서만 진행할 수 있습니다.

기록과 결과 공유

최고 기록은 직접 맞힌 수가 많은 순, 같으면 힌트 사용과 다른 답 확인 횟수가 적은 순입니다. 시간은 참고로만 표시하며 빨리 푼 사람을 우선하지 않습니다. 같은 오답을 그대로 다시 확인해도 횟수를 더하지 않습니다.

결과 공유에는 맞힌 수·힌트·정답 보기 횟수와 간단한 표시만 들어갑니다. 문제나 정답은 넣지 않으므로 아직 풀지 않은 사람과도 결과를 나눌 수 있습니다. 큰 글씨와 어두운 화면은 시작 화면이나 게임 아래의 버튼에서 바꿀 수 있습니다.
