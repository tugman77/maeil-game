## 남은 제한

Safari·Edge·삼성 인터넷과 실제 휴대폰 터치는 직접 검수하지 못했다. 컴퓨터는 공개 정보의 휴리스틱으로 움직이고 모든 난이도에서 스톱을 우선하는 연습 상대다. 전문 기력·암호학적인 조작 방지는 제공하지 않는다. 술잔 피 전환, 보너스패, 첫뻑 추가점, 나가리 다음 판 배수 등은 채택하지 않으며 도움말에 명시했다.

## 상대 자리·먹은 패·차례 연출 개선 — 2026-11-26

- 상단 컴퓨터 자리: 직접 그린 원·점·곡선 얼굴, 이름, 뒷면 손패와 장수, 점수·고·흔들기 횟수, 차례 강조와 생각 중 표시, 고/스톱 말풍선. 상용 게임의 그림·화면 자산은 사용하지 않았다.
- 양쪽 먹은 패를 광·열끗·띠·피 네 무더기로 겹쳐 항상 표시. 종류별 장수·기본 점수와 홍단·청단·초단·고도리 진행을 표시한다. 피 장수는 쌍피를 반영한 가치이며 접근성 이름에는 실제 패 장수도 남긴다.
- 화면 전용 presentation.js에서 내기 → 더미 크게 공개 → 바닥에 내려놓기 → 획득 → 사건 알림 순서로 재생한다. 보통은 이동 400ms, 더미 공개·사건 1,000ms. 느리게/빠르게, 기기 기본값을 따르는 움직임 줄이기 설정을 별도 키에 저장한다. 컴퓨터와 직전 차례 다시 보기에도 같은 속도를 적용한다.
- 한 줄 기록·직전 차례 전체 다시 보기 추가. 다시 보기는 저장 로그에서 복원하며 점수·로그·추천·통계는 바꾸지 않는다. 선택 대기 중 엔진이 보관하는 낸 패·뒤집은 패도 바닥에서 계속 보여 준다.
- 규칙·점수·AI·날짜 시드·게임 저장 v1 형식은 유지했다. 행동 결과는 연출 전에 저장하고 입력을 잠근다. 처음·일시정지·페이지 이탈 시 연출 타이머를 취소하며 이어할 때 저장된 결과부터 재개한다. 종료 연출 도중 재접속한 경우도 결과를 한 번만 기록한다. 실제 더블클릭의 늦은 이벤트가 이미 낸 패의 선택을 되살리지 않도록 현재 상태를 다시 검사한다.

## 2차 모바일 보완 — 2026-11-26

- 시작 그림은 화면 높이에 따라 줄이던 제한을 제거하고 SVG별 실제 비율로 높이를 확보했다. 이어하기·큰 글씨·오늘 도전 완료 상태에서도 크기를 유지한다. 홈 전체 게임 카드에도 같은 비율을 적용했다. 그림 내용·색은 그대로다.
- Chrome의 CSS viewport 390×664에서 실제 SVG 내용 경계 실측: 스도쿠 317.8×317.8px, 2048 318.3×318.3px, 바둑 321.3×321.3px, 리버시 320.8×320.8px, 오목 323.1×303.1px, 장기 317.8×381.3px, 블록 318.3×339.1px. 홈 정사각 그림은 약 153px로 각 그림 칸을 채운다.
- 맞고는 빈 종류의 패 상자를 접고, 획득한 종류만 작은 무더기로 펼친다. 손패 10장은 달과 그림이 모두 보이도록 가로로 겹친다. 한 줄 기록의 가로 폭을 제한하고 설정은 화면 안에서 여는 창으로 옮겼다. 흔들기·폭탄은 내기 버튼 옆에 배치한다. 바닥패는 남는 높이를 사용한다.
- 가져올 패 선택·고/스톱 선택을 바닥패 위에 겹쳐 띄운다. 390×664 패 선택 창은 x=13px, y=188.2px, 폭 364px, 높이 122px로 화면 안에서 표시된다.
- 초기 손패 10장·중반·바닥패 다수·두 종류의 짝 선택·고/스톱·폭탄 배치 모두 문서 높이 664px(390×664), 600px(360×600), 가로 넘침 0px. 큰 글씨·다크 조합도 동일하다. 문서 자체를 숨겨 통과시키지 않고 각 필수 영역·손패·버튼의 화면 내 좌표도 검사한다.
