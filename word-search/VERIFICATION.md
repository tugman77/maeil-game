# 한글 단어 찾기 검증 — 2026-11-29

생활 주제 12종에서 쉬움 5×5·4단어, 보통 6×6·6단어, 어려움 7×7·8단어를 만든다. 날짜별 도전은 보통 난이도로 고정한다. 단어의 양끝을 차례로 누르며, 반대 순서로 선택해도 인정한다.

## 자동 검사

- `node --test tests/*.test.js`: 347개 통과, 실패 없음. 신규 단어 찾기 전용 12개 포함.
- `node tests/common.test.js`, `node tests/games.test.js`, 스도쿠 game/generator/storage 검사 통과.
- 3개 난이도 각각 365판, 총 1,095판을 독립적인 여덟 방향 검색으로 확인했다. 모든 목표 단어는 정확히 한 번 존재하며 허용된 방향에 놓인다.
- 양끝 역순·잘못된 경로·중복 선택, 힌트·되돌리기, 변조/손상 저장 거부, 일시정지·이어하기, 완료 시 기록 한 번만 반영, 지난 날짜 출석과 저장 차단 환경을 확인했다.
- 공통 난수·스도쿠 생성기·기존 기록 키는 수정하지 않았다.

## 화면 확인

Chrome의 로컬 HTML에서 PC와 반응형 360×800 화면을 확인했다. 큰 글씨와 밝은/어두운 화면에서 글자가 보이며 선택·찾음·힌트에 색 외의 테두리/밑줄을 제공한다. 선택 전후 PC 글자판 크기가 같고, 완료 체크가 단어 목록 너비를 바꾸지 않는다. 새로고침 후 찾은 단어와 힌트가 복원된다.

브라우저 연결 호스트와 로컬 HTTP 서버가 제한되어 네이티브 Chrome UI로 로컬 파일을 확인했다. 실제 휴대폰·Safari·Edge·삼성 인터넷 조작과 오프라인 재접속은 미검수다. 배포 결과는 GitHub Pages 실행 상태 및 공개 파일 응답으로 별도 확인한다.
